# HEAR_APP

Ubicarse en la carpeta del proyecto

```bash
cd HEAR_APP
```

Crear un virtual envoriment. Se recomienda usar la version de 3.11.\* de python

```bash
python -m venv venv
```

Activar entorno virtual .\env\Scripts\activate

```bash
.\venv\Scripts\active
```

Instalar dependencias para el proyecto

```bash
pip install -r requirements.txt
```

ver tofo lo que tenemos instalado

```bash
pip list

# or

pip freeze
```

Correr o uniciar proyecto

##### Optinal `python .\src\[app.py](http://app.py/)`

```bash
python src/app.py
```
